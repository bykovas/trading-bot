# Blynai Capital Decision Mockup

Standalone static prototype for the first Blynai Capital hero screen.

Open `index.html` directly in a browser. No build step and no backend required.

## Intent

This is one high-fidelity Decision Explanation screen for a single `BUY / LONG micro` decision on `SOL/EUR`.

It is intentionally not a full dashboard. The goal is to establish the product's visual identity:

- premium dark fintech cockpit
- prominent Blynai Capital brand
- abstract pancake coin / fund-seal motifs
- traceable chart, score, risk, execution, and audit data
- serious engineering with quiet meme-fund personality
